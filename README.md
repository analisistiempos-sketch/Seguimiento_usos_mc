# Tablero de Usos

App Streamlit que visualiza los usos del sistema de transporte. Lee los datos
desde el repo de GitHub (carpeta datos/) configurado con las variables:

- USOS_FUENTE=github
- GITHUB_REPO=usuario/seg_usos
- GITHUB_RUTA=datos
- GITHUB_BRANCH=main
- GITHUB_TOKEN=<token con permiso de lectura>
- USOS_SHAREPOINT_DIR=/tmp/usos_datos (cachÃ© local en el Space)
